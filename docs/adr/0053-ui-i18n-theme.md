# UI: DaisyUI, Lingui, themes, Liquid Glass

Web client is Solid + Vite PWA with Tailwind and DaisyUI primitives, Biome for lint/format, and lefthook pre-commit alongside Rust fmt/clippy. i18n uses Lingui with locales en, ru, and es: profile override, else system language, else en. Appearance is system, light, or dark via `data-theme`. Visual direction is Apple HIG–inspired Liquid Glass (translucent panels, soft materials) on top of DaisyUI—not stock Daisy cosmetics.
