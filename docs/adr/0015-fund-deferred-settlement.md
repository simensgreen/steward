# Fund accumulates; settlement is deferred and strategic

Members buy, contribute, and spend on their own. The Fund accumulates per-member position via Settlement Strategy; settlement is optional and can wait. Purchases do not require a request each time. Money Requests can be In Progress while fulfilling. Trust Level chooses confirm-on-receive vs auto-accept. **Directional actions and the Anya/Borya balance example are specified in ADR-0021.**
