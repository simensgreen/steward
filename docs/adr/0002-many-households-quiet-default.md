# Many Households, quiet default

A person may belong to multiple Households (e.g. primary home and a cottage). The product must support that without constant Household pickers: exactly one membership → no choice UI; several → use Default Household (last used or pinned) and only surface a switcher when the user opts in or the action is Household-ambiguous. Multi-Household is a first-class model, not a bolted-on afterthought, but the common path stays one-tap.
